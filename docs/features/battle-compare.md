# 恶意斗虫（多主播对比分析）

## 概述

多主播数据对比分析功能，支持选择多个主播、日期范围和对比指标进行可视化比较。

## 组件

- `AnchorBattle.vue` — 恶意斗虫主组件
- `ChartComponent.vue` — 图表组件

## 功能特性

### 主播选择

支持选择多个主播进行对比分析。

### 日期范围

支持选择起始月份和结束月份，查看特定时间段的数据变化。

### 对比指标（13种）

| 序号 | 指标 | 说明 |
|------|------|------|
| 1 | 直播时长 | 直播总时长 |
| 2 | 礼物收入 | 礼物收入金额 |
| 3 | 舰长收入 | 舰长收入金额 |
| 4 | SC 收入 | Super Chat 收入 |
| 5 | 总营收 | 总收入 |
| 6 | 新增总督 | 新增总督数量 |
| 7 | 新增提督 | 新增提督数量 |
| 8 | 新增舰长 | 新增舰长数量 |
| 9 | 新增粉丝团 | 新增粉丝团数量 |
| 10 | 弹幕数 | 弹幕总数 |
| 11 | 平均同接 | 平均同接人数 |
| 12 | 最高同接 | 最高同接人数 |
| 13 | 新增粉丝数 | 新增关注数 |

### 图表特性

- **尺寸**: 8000x1800px 超大画布
- **横向滚动**: 支持横向滚动查看所有数据点
- **不同点形状**: 每个主播使用不同的点形状标识
  - circle, rect, triangle, star, diamond, cross, rectRot, line, dash
- **图例位置**: 图表上方，支持点击复选框显示/隐藏对应主播

### 交互功能

- 显示/隐藏特定主播的折线
- 导出图表为 PNG 图片
- Debug 面板查看原始数据

### 数据获取优化

- 30 秒超时配置
- 自动重试机制（最多 3 次，间隔 2 秒）
- 智能检测数据完整性
- 刷新/补全数据功能
- 数据缺失警告提示
