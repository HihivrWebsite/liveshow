# 粉丝重合度查询

## 功能概述

分析两个主播粉丝团的重叠情况，展示双向重叠百分比、等级分布和舰长等级统计。

## 数据来源

上游 API：`https://fans.harei.cn`（bilifanscache 服务）

- `GET /fans?room_id=<id>` — 获取某主播全部粉丝 UID + 牌子等级 + 舰长等级
- 缓存刷新周期：约 6.5 分钟（~130 个主播，每个 3 秒间隔）

## 计算逻辑

- **双向百分比**：A&B = |A∩B|/|A|×100%，B&A = |A∩B|/|B|×100%
- **等级分布**：交集粉丝按牌子等级分桶（1-10/11-20/21-30/31-40/41-50/51-60）
- **舰长等级**：舰长(3)/提督(2)/总督(1) 各级别统计
- **共同上舰**：双方均有上舰的粉丝数

## 前端入口

1. 右侧抽屉 → 🔍 粉丝重合度查询 按钮
2. 导航表格上方 → 🔍 粉丝重合度查询 按钮

## 使用方法

1. 在导航表格中勾选 **2 个主播**
2. 点击 🔍 粉丝重合度查询 按钮
3. 组件自动调用 API 并展示分析结果（总览卡片 + 双向百分比 + 等级分布柱状图 + 舰长统计）

> 注：无需手动选择主播，组件直接读取导航表格中已勾选的前 2 个主播。

## 后端端点

`GET /gift/fans_overlap?room_id_a=<id>&room_id_b=<id>`

代理上游 bilifanscache API，返回交集计算结果。

## 组件

`FanOverlap.vue` — 全屏覆盖层组件，接收 `initialAnchors` prop（已勾选主播），挂载后自动调用 API 并展示 Chart.js 柱状图结果。无需手动选择主播。
