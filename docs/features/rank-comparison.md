# 排名对比功能

## 功能概述

排名对比功能允许用户选择多个主播，对比他们在指定时间范围内各指标的排名变化趋势。

## 功能特性

- **多主播排名对比**：支持选择2个及以上主播进行排名对比
- **多指标支持**：支持13种不同指标的排名对比
  - 直播时长、礼物收入、舰长收入、SC收入、总营收
  - 新增总督/提督/舰长、新增粉丝团、弹幕数
  - 平均同接、最高同接、新增粉丝数
- **累计排名计算**：基于累计值计算每日排名
- **头像显示**：图表数据点使用主播头像作为标记
- **图例控制**：支持通过图例切换显示/隐藏特定主播
- **数据缓存**：2小时缓存机制，减少API调用
- **图表导出**：支持将排名变化图导出为PNG图片

## 使用方法

1. 在主页导航表格中勾选至少2个主播
2. 点击"📊 排名对比"按钮
3. 选择日期范围（起始月份和结束月份）
4. 选择对比指标
5. 查看排名变化图表

## 技术实现

### 组件结构

- `RankComparison.vue`：排名对比主组件
- 复用 `HeaderSection.vue` 和 `FooterSection.vue`
- 使用 Chart.js 绘制折线图

### 核心算法

1. 按日期聚合每个主播的指标值
2. 计算累计值
3. 每日根据累计值降序排序确定排名
4. 绘制排名随时间变化的折线图

### 图表特性

- Y轴反转：第1名在顶部
- Canvas尺寸：4000x1200
- 数据点头像：使用主播头像作为数据点标记
- 悬停提示：显示主播名称和具体排名
