# 页眉操作入口

## 概述

`HeaderSection.vue` 提供页眉操作按钮和功能指南入口，其中包含“关注咿喔ioo_谢谢喵”跳转按钮。

## 关注咿喔ioo按钮

- 按钮文字：`关注咿喔ioo_谢谢喵`
- 跳转地址：`https://space.bilibili.com/85996232`
- 打开方式：新标签页
- 展示位置：
  1. 页眉“进入向阳Hihi粉丝站主站 / 为成为向阳人而骄傲”按钮正下方
  2. 功能指南欢迎语正下方

## 视觉规范

- 使用语义化链接并以按钮样式呈现
- 主色为需求指定的 `#B22222`，作为六色色板的明确例外
- 文字使用 `#FFF3D0`，描边和光晕使用 `#F6B100`
- 圆角遵循按钮 `999px` 规范
- 纯 CSS 实现呼吸光晕、斜向高光扫过和星光闪烁，不依赖 GSAP
- Hover 时增强发光并轻微缩放，键盘聚焦时显示金色焦点轮廓
- `prefers-reduced-motion: reduce` 时关闭循环动画并保留静态高光

## 响应式规则

- 桌面端使用较大的字号和内边距
- 768px 以下限制最大宽度，避免按钮超出容器
- 480px 和 360px 断点进一步缩小字号与内边距
- 始终设置 `max-width: 100%`，防止窄屏横向溢出
