# 页眉操作入口

## 概述

`HeaderSection.vue` 提供页眉主站入口、关注入口和功能指南入口。

## 主站入口

- 页眉保留主站按钮第一行“进入咿喔io粉丝站主站”
- 已删除按钮内第二行“为成为向阳人而骄傲”
- 功能指南中没有重复的主站按钮或标语
- 新域名仍由页脚“咿喔io粉丝站”链接显示为 `https://yioio.top`
- 页面标题和功能指南标题统一显示“咿喔io粉丝站维阿PSP斗虫榜”和新域名 `yioio.top`

## 关注咿喔ioo按钮

- 按钮文字：`关注咿喔ioo_谢谢喵`
- 跳转地址：`https://space.bilibili.com/85996232`
- 打开方式：新标签页
- 展示位置：
  1. 页眉功能指南按钮上方
  2. 功能指南欢迎语正下方

## 视觉规范

- 使用语义化链接并以按钮样式呈现
- 主色为需求指定的 `#b1646e`，作为六色色板的明确例外
- 文字使用 `#FFF3D0`，描边和光晕使用 `#F6B100`
- 圆角遵循按钮 `999px` 规范
- 纯 CSS 实现呼吸光晕、斜向高光扫过和星光闪烁，不依赖 GSAP
- Hover 时增强发光并轻微缩放，键盘聚焦时显示金色焦点轮廓
- `prefers-reduced-motion: reduce` 时关闭循环动画并保留静态高光

## 域名迁移提示

- 功能指南 `.guide-content` 第一行显示域名迁移提示
- 文案：`网站域名由dc点hihivr点top迁移至dc点yioio点top 过渡期结束后原网址将无法访问，请互相转达。`
- 文字使用大红色 `#ff0000`，闪光仅在 `#ff0000`、`#ff6b9d`、`#fff3d0` 等红/粉/白系颜色间变化
- 禁止 `#f6b100` 或橙黄色过渡
- 新增 `domain-migration-flash` keyframes
- `prefers-reduced-motion: reduce` 时关闭动画并保留静态提示

## 响应式规则

- 桌面端使用较大的字号和内边距
- 768px 以下限制最大宽度，避免按钮超出容器
- 480px 和 360px 断点进一步缩小字号与内边距
- 始终设置 `max-width: 100%`，防止窄屏横向溢出
