# 主播列表功能

## 概述

展示维阿（VirtuaReal）和PSP（PSPlive）工会主播的收入数据，支持筛选、排序和数据可视化。

## 组件

- `AnchorList.vue` — 主播列表主组件
- `BaseCard.vue` — 基础卡片组件，用于显示主播信息
- `NavigationTable.vue` — 导航表格组件，提供快速跳转

## 功能特性

### 工会筛选

支持按工会筛选：全部 / VR（VirtuaReal）/ PSP（PSPlive）

### 月份选择

支持按月份查看历史数据，通过月份选择器切换。

### 数据展示

每个主播卡片显示：
- 主播头像（圆形，60px，从 Bilibili API 获取）
- 主播名称、标题
- 关注数、粉丝团数量
- 礼物收入、舰长收入、SC收入、总营收
- 直播时长、有效天数
- 舰长/提督/总督数量
- 直播状态（开播/未开播）

### 数据可视化

- **营收占比饼图** — 展示各主播收入占比
- **VR/PSP 工会对比图** — 对比两个工会的数据

### 分析功能

- 回归分析
- 聚类分析

### 截图导出

支持多选主播后导出数据截图：

1. 在导航表格中勾选需要导出的主播
2. 点击"📸 导出截图"按钮
3. 选择月份范围（起始月和结束月）
4. 点击"确定导出"生成并下载 PNG 图片

导出内容包含：
- 网站顶栏（网站标题 + 网址）
- 致谢文字（千秋紫莹 API 致谢）
- 使用说明
- 数据表格（头像 + 主播名 + 各数据字段）

图片自动下载为 PNG 格式，字段自动适配：表格列基于 `getExportFields` 配置，新增字段自动包含在导出中。

依赖：`html2canvas`（已安装）

### 数据格式化

- 货币格式化：`formatCurrency(value)`
- 数字格式化：`formatNumber(value)`（支持千位分隔符解析）
- 百分比计算：`calculatePercentage(value, total)`
- 时长计算：`calculateDuration(startTime, endTime)`

### 响应式设计

- 适配不同屏幕尺寸
- 窄屏设备支持横向滚动
- 断点：1300px、1200px、1024px、768px、600px、480px、360px
