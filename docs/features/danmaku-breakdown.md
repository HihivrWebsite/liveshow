# 弹幕分级统计

## 功能概述

主播直播数据新增弹幕分级统计，按用户身份分为普通弹幕、舰长弹幕、提督弹幕、总督弹幕。

## 数据来源

上游 API (vr.qianqiuzy.cn/psp.qianqiuzy.cn) 的 `danmaku` 二级对象。

| 字段 | 说明 |
|------|------|
| `danmaku.total` | 月总弹幕数 |
| `danmaku.captain` | 舰长弹幕数 |
| `danmaku.admiral` | 提督弹幕数 |
| `danmaku.governor` | 总督弹幕数 |
| `danmaku.normal` | 普通弹幕数 |

## 展示位置

- 主播卡片：总弹幕 + 分级弹幕（当数据存在时）
- 导出截图：弹幕分级列
- 直播会话详情：弹幕数 + 分级弹幕 + 趋势图
- 展开详情：弹幕分级字段
- 恶意斗虫：新增 4 个指标选项（舰长弹幕、提督弹幕、总督弹幕、普通弹幕）
- 排名对比：新增 4 个指标选项
