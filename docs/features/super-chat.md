# Super Chat 历史功能

## 概述

展示主播的 Super Chat（SC）历史记录。

## 组件

- `SuperChatDetail.vue` — SC详情组件

## 功能特性

### SC 列表

- 显示 Super Chat 历史消息
- 按时间排序显示
- 包含发送者信息（用户名、用户ID）
- 显示金额
- 显示消息内容

### SC 颜色等级

Super Chat 根据金额显示不同的背景和字体颜色：

| 金额范围 | 背景颜色 | 字体颜色 |
|----------|----------|----------|
| 低于 10 元 | 银色 | 深色 |
| 10-100 元 | 蓝色 | 默认 |
| 100-1000 元 | 金色 | 红色 |
| 1000 元以上 | 红色 | 金色 |

### 数据来源

通过 `/gift/sc` API 端点获取数据。

### 页面布局

- 包含返回按钮
- 显示额外的网站推广信息
- 响应式设计
