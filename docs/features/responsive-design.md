# 响应式设计

## 概述

项目采用响应式设计，确保在不同设备和屏幕尺寸下都能正常显示。

## 响应式断点

| 断点 | 目标设备 |
|------|---------|
| 1300px | 大屏桌面 |
| 1200px | 桌面 |
| 1024px | 小桌面/平板横屏 |
| 768px | 平板 |
| 600px | 大屏手机 |
| 480px | 手机 |
| 360px | 小屏手机 |

## 横向滚动支持

- 移除了 `html, body { overflow-x: hidden; }` 限制
- 表格容器添加 `display: block; white-space: nowrap;` 支持横向滚动
- 主内容区域添加 `overflow-x: auto` 属性
- 在极窄屏幕上整个页面内容可以横向滚动

## 组件适配

### BaseCard 组件

- 响应式布局，适配不同屏幕尺寸
- 包含悬停动画效果
- 支持自定义字段显示

### NavigationTable 组件

- 适配不同类型的数据显示
- 支持点击跳转到对应卡片位置
- 支持中键点击在新标签页打开

### 表格显示

- 窄屏设备上表格不截断，支持横向滚动
- 所有数据在任何屏幕尺寸下完整显示

## 测试工具

- `responsive_test.html` — 手动响应式测试页面
- `responsive_test_optimized.html` — 优化版测试页面
- `scroll_test.html` — 横向滚动测试页面
- `test_responsive.js` — 自动化响应式测试脚本

## 测试方法

1. 访问 `http://localhost:3000`
2. 使用浏览器开发者工具模拟不同设备尺寸
3. 特别测试 320px、360px、480px 等窄屏尺寸
4. 验证表格和其他宽内容是否可以横向滚动
5. 确认所有信息都能完整显示
