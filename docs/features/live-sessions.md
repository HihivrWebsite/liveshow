# 直播会话详情功能

## 概述

展示特定主播的详细直播数据，包括每场直播的收入、弹幕、同接等信息。

## 组件

- `LiveSessions.vue` — 直播会话主组件
- `BaseCard.vue` — 基础卡片组件
- `NavigationTable.vue` — 导航表格组件

## 功能特性

### 会话列表

显示指定主播的所有直播会话：
- 开始/结束时间
- 直播时长（分钟）
- 礼物收入、舰长收入、SC收入、总营收
- 弹幕数
- 平均同接、最高同接
- 开播/下播时的舰长数量变化
- 开播/下播时的粉丝团数量变化

### 数据图表

提供直播数据折线图，可视化收入趋势。

### SC 历史

显示该主播的 Super Chat 历史记录。

### 新增粉丝数（懒加载）

- 初始加载时不计算 `new_fans_count`
- 用户展开会话详情时按需计算
- 通过 `/gift/session_fans_change` 端点获取

### 跳转功能

- 跳转到直播间按钮
- 中键点击可在新标签页打开

### 多月份统计

支持查看多个月份的统计数据。
